Cookie & Session Analyzer

Paste raw HTTP response headers, Set-Cookie lines, a Cookie: request header, or a JSON cookie export. The analyzer audits every cookie against OWASP Session Management guidance — security flags, prefix rules, token entropy, JWT weaknesses, tamperable client-side state — then grades the configuration and writes the hardened headers for you.

🔒 Everything runs locally in your browser. No cookie, token or header ever leaves this page.

Tip: on a site you own, run copy(document.cookie) in DevTools and paste it here — any session token it returns is already readable by an XSS payload.

What it checks

      

        
Transport & script accessMissing Secure / HttpOnly on session
            cookies, SameSite=None without Secure, missing SameSite (CSRF).

        
ScopeOver-broad Domain (sibling-subdomain exposure), __Host- /
            __Secure- prefix violations browsers silently reject.

        
LifetimePersistent session tokens, multi-year expiry, already-expired cookies.

        
Token strengthEstimated entropy vs. OWASP's 64-bit minimum, numeric / sequential IDs,
            Unix-timestamp IDs, low character diversity.

        
JWTDecodes header & payload: alg: none, missing / long exp,
            sensitive claims, JWT stored where JavaScript can read it.

        
Client-side stateBase64 / URL-encoded / JSON values exposing roles, user IDs, admin flags or
            PII that a user could edit and replay.
